# تحویل اولویت ۱۰ — پرتال نماینده و CRM موبایل

تاریخ: ۲۸ سپتامبر ۲۰۲۶ (تهران)

اولویت ۱۰ در محدودهٔ **نمونهٔ آزمایشی** به همان پروژهٔ ASP.NET Core MVC و پیش‌نمایش یکپارچه اضافه شد. معماری Razor، HTMX، JavaScript و CSS سازگار با Tailwind حفظ شده است.

## موارد پیاده‌شده

- پرتال مختص نماینده: کالا/قیمت/موجودی نمونه، مانده و سررسید، هدف و عملکرد، دریافت صورتحساب CSV و کاربران همان نمایندگی.
- درخواست سفارش، سرنخ، شکایت، Claim، دعوت و لغو دسترسی؛ کارتابل بررسی داخلی، پاسخ عمومی، لغو و کنترل نسخه.
- حفاظت نمونهٔ ۳۰روزهٔ سرنخ با کلید نرمال‌شده و کنترل یکتایی DB؛ سفارش متصل فقط پس از گردش داخلی.
- حساب جدید PendingActivation با نقش ثابت DealerUser؛ لغو نقش، SecurityVersion و نشست مرتبط پس از تأیید مدیر.
- برنامهٔ روزانهٔ بازدید، شروع، پایان، لغو، یادداشت نتیجه و موقعیت اختیاری با رضایت.
- صف موقت آفلاین، replay با OperationId، ارسال ترتیبی، timeout، TTL و توقف روی تعارض/نشست نامعتبر.
- اتصال نتیجهٔ بازدید به Customer 360 و انتقال/بازگردانی روابط جدید در Merge/Unmerge.
- مدل EF، migration و snapshot، اسکریپت ارتقا/بازگشت، سازگاری شناسه‌های migration قدیمی، دادهٔ نمونه و راهنمای اجرا.
- مسیرهای جدید در همان HTML یکپارچه؛ دادهٔ درخواست/رسیدگی/سرنخ و بازدید مشترک است.

## شواهد و محدودیت اعتبارسنجی

| بررسی | نتیجهٔ این محیط |
|---|---|
| ساخت Release و تولید Razor | انجام‌شده با SDK 10.0.112 و runtime 10.0.12؛ هر هشت پروژه، صفر خطا و صفر هشدار |
| آزمون‌های تجمعی معماری و سرویس، شامل P10 | اجراشده و موفق |
| آزمون‌های HTTP/MVC/HTMX و امنیت، شامل P10 | اجراشده و موفق |
| نگاشت EF، snapshot، FK، concurrency و unique index | موفق؛ تطابق snapshot و نگاشت ویژگی‌های ذخیره‌شدنی نیز کنترل شد |
| آزمون JavaScript صف موبایل | اجراشده و موفق |
| منطق واقعی HTML یکپارچه در DOM harness | اجراشده و موفق؛ آزمون ظاهری مرورگر نیست |
| اجرای واقعی migration/rollback و round-trip | موفق روی SQL Server 2025 Developer، نسخهٔ 17.0.5005.3، در DB موقت آزمایشی |
| اسکریپت‌های SQL مستقل | ارتقای P4/P5/P6/P7/P8/P10 هرکدام دوبار؛ rollback و ارتقای مجدد P10 هرکدام دوبار، موفق |
| اجرای واقعی Kestrel با .NET 10 | ورود HTTPS مدیر و نماینده، صفحات موبایل/پرتال، health و فایل‌های CSS/JS موفق |
| آزمون ظاهری Playwright | تأیید نشده؛ Chrome 154.0.8037.57 نصب شد، اما محیط ایجاد سوکت داخلی مرورگر را با `Operation not permitted` متوقف کرد |
| GitHub CI / استقرار آنلاین | نتیجه‌ای دریافت نشده و استقرار جدیدی انجام نشده |

فایل ورود اصلی `index.html` است؛ همان محتوا در `preview/crm-unified.html` قرار دارد. برای پرتال `dealer.user` و برای بررسی/بازدید `sales.manager`، با رمز نمونه `Demo@1405` وارد شوید. فایل را در صورت محدودیت نمایشگر پیوست، دانلود و در مرورگر باز کنید.

## اصلاحات حاصل از اجرای واقعی

- snapshot دستی و ناقص با snapshot استاندارد EF جایگزین شد؛ آزمون `HasPendingModelChanges` مانع تحویل snapshot ناسازگار می‌شود.
- نگاشت ۱۲ ویژگی فقط‌خواندنی اصلاح شد؛ شامل نسخهٔ امنیتی نشست، ثبت‌کنندهٔ نقش، ثبت‌کنندگان تاریخچه، شناسهٔ مشتری مقصد ادغام، امتیاز تکراری، احتمال مرحله، تعداد سفارش و انحصار قلمرو. ستون‌ها قبلاً در migrationها وجود داشتند؛ شناسهٔ تاریخچه تغییر نکرد.
- خطای کامپایل batch در migrationهای قدیمی و اسکریپت‌های ارتقا رفع شد: دستورات وابسته به ستون تازه، پس از `ALTER TABLE` کامپایل می‌شوند.
- اسکریپت‌های مستقل P8 از migration تولید می‌شوند و تاریخچه، baseline، تراکنش و قفل را مانند P10 کنترل می‌کنند؛ نقص تاریخچه مانع ارتقای بعدی نمی‌شود.
- انتخاب SDK در `global.json` با feature bandهای .NET 10 سازگار شد. راهنمای ورود محلی از HTTPS استفاده می‌کند؛ کوکی Secure حفظ شده است.
- آزمون SQL از DB آزمایشی محافظت‌شده استفاده می‌کند و مقدارهای فقط‌خواندنی، کنترل نسخه، یکتایی عملیات و اجرای تکراری اسکریپت‌ها را بررسی می‌کند.

خروجی ثبت‌شدهٔ آزمون‌ها در `docs/priority-10-test-output.txt` است. اسکریپت‌ها روی DB واقعی سازمان اجرا نشده‌اند. نتیجهٔ SQL Server 2025 محلی به‌جای نتیجهٔ SQL Server 2022 در GitHub CI گزارش نمی‌شود.

## مرز تکمیل

دو بررسی باقی‌ماندهٔ محلی، یعنی ساخت/اجرای .NET 10 و آزمون واقعی SQL، انجام شد. آزمون ظاهری مرورگر و سناریوی قطع شبکه در مرورگر واقعی هنوز باید در محیط دارای مجوز اجرای مرورگر تأیید شود؛ آزمون JavaScript صف جای آن را نمی‌گیرد. نتیجهٔ GitHub CI و استقرار آنلاین نیز دریافت نشده است. اتصال واقعی ERP/IdP، ارسال دعوت، عکس با اسکن، اپ بومی، مسیریابی نقشه و Offline رمزنگاری‌شده پس از بسته‌شدن مرورگر خارج از محدودهٔ نمونه هستند.
