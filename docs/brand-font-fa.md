# فونت سازمانی: ایران‌سنس (از نسخه 1.9.4)

فونت اصلی سامانه **IRANSansX** است. ترتیب فونت‌ها در متغیر `--font` فایل `site.css` این است:

`IRANSansX` ← `IRANSans` (نسخهٔ نصب‌شده روی رایانه) ← `Vazirmatn` ← `Segoe UI` ← `Tahoma`

## چرا فایل فونت در مخزن نیست؟

ایران‌سنس فونت تجاری است (فونت‌آیران) و انتشار فایل آن بدون مجوز مجاز نیست. برای همین فایل‌ها همراه کد نیامده‌اند. هر سازمانی که مجوز وب فونت را دارد، فایل‌های خودش را اضافه می‌کند.

## فعال‌سازی

1. فایل‌های woff2 دارای مجوز را با این نام‌ها در `src/Crm.Web/wwwroot/fonts/` بگذارید:

   | وزن | نام فایل | الزامی |
   |---|---|---|
   | 400 | `IRANSansX-Regular.woff2` | بله |
   | 500 | `IRANSansX-Medium.woff2` | خیر |
   | 600 | `IRANSansX-DemiBold.woff2` | خیر |
   | 700 | `IRANSansX-Bold.woff2` | خیر |
   | 800–900 | `IRANSansX-ExtraBold.woff2` | خیر |

2. برنامه را دوباره اجرا کنید (`dotnet run --project src/Crm.Web`). وجود فایل `IRANSansX-Regular.woff2` هنگام شروع برنامه بررسی می‌شود. اگر این فایل باشد، برگهٔ `css/fonts.css` به همهٔ صفحه‌ها، از جمله صفحهٔ ورود، اضافه می‌شود.

- **وزن‌های اختیاری:** اگر وزنی را نگذارید، مرورگر نزدیک‌ترین وزن موجود را استفاده می‌کند.
- **اعداد فارسی:** نسخهٔ FaNum (مثلاً `IRANSansXFaNum-Regular.woff2`) را با همین نام‌ها ذخیره کنید.
- **بدون فایل‌ها:** اگر فایل‌ها نباشند، `fonts.css` بارگذاری نمی‌شود و خطای ۴۰۴ هم پیش نمی‌آید. در این حالت اگر ایران‌سنس روی رایانهٔ کاربر نصب باشد، همان نمایش داده می‌شود. در غیر این صورت فونت‌های بعدی فهرست جایگزین می‌شوند.
- **سیاست امنیتی محتوا (CSP):** فونت از همان دامنهٔ سامانه بارگذاری می‌شود (`font-src 'self'`) و به CDN یا سرویس بیرونی نیازی نیست.

## پیش‌نمایش آفلاین

`index.html` یک فایل تکی است و فایل فونت را همراه ندارد. اگر ایران‌سنس روی رایانه نصب باشد، با همان نمایش داده می‌شود.
