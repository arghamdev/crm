# رنگ سازمانی و توکن‌های رنگ (از نسخه 1.9.1)

همهٔ رنگ‌ها به شکل متغیر CSS در `:root` فایل `src/Crm.Web/wwwroot/css/site.css` تعریف شده‌اند. پیش‌نمایش آفلاین هم هنگام ساخت همین متغیرها را برمی‌دارد. در صفحه‌ها و کامپوننت‌های تازه رنگ را مستقیم ننویسید و از این متغیرها استفاده کنید.

| کاربرد | متغیر | مقدار |
|---|---|---|
| منوی اصلی و هویت سامانه | `--navy-900` | `#14263D` |
| دکمه اصلی، لینک و بخش انتخاب‌شده | `--primary-700` | `#1D4ED8` |
| دکمه اصلی هنگام قرارگیری نشانگر | `--primary-800` | `#1E40AF` |
| پیشرفت درخواست و تأکید مکمل | `--accent-700` | `#0F766E` |
| زمینه عمومی صفحات | `--page` | `#F4F7FB` |
| زمینه فرم‌ها، جدول‌ها و کارت‌ها | `--surface` | `#FFFFFF` |
| متن اصلی و عنوان‌ها | `--ink` | `#0F172A` |
| متن توضیحی و برچسب‌های فرعی | `--ink-2` | `#475569` |
| خطوط جداکننده جدول و کارت | `--line` | `#D8E0EB` |
| مرز کادرهای ورودی | `--field-border` | `#64748B` |
| حلقه تمرکز صفحه‌کلید | `--focus` / `--focus-ring` | `#1D4ED8` |

| وضعیت | متن و آیکون | زمینه |
|---|---|---|
| موفق، تأییدشده یا تکمیل‌شده | `--green-700` = `#166534` | `--green-100` = `#DCFCE7` |
| هشدار یا نیازمند توجه | `--amber-700` = `#92400E` | `--amber-100` = `#FEF3C7` |
| خطا، تأخیر جدی یا اقدام مخرب | `--red-700` = `#B91C1C` | `--red-100` = `#FEE2E2` |
| اطلاع‌رسانی یا وضعیت فعال | `--blue-700` = `#1D4ED8` | `--blue-100` = `#DBEAFE` |

برچسب‌های وضعیت (`badge--*` و `pill--*`)، کاشی‌های فهرست‌ها و رنگ سررسید (`due--*`) همه از همین متغیرها رنگ می‌گیرند. سبزآبی فقط برای نوار پیشرفت، امتیاز و کیفیت داده و تأکید مکمل به کار می‌رود، نه برای دکمه یا لینک. حالت تیره همین متغیرها را با معادل تیره بازتعریف می‌کند.
