# بررسی و اصلاح بازشدن صفحات و یکپارچگی رابط

تاریخ: ۲۷ سپتامبر ۲۰۲۶

## علت‌های تأییدشده

۱. فایل `crm-priority9-reports.html` یک نمایش مستقل گزارش بود. گزینه‌های مشتریان، فرصت‌ها و نمایندگان در سایدبار آن از نوع متن `span` بودند و به هیچ صفحه‌ای وصل نمی‌شدند. صفحه ورود مشترک و ارتباط داده با سایر پیش‌نمایش‌ها نیز نداشت.

۲. README همین فایل جزئی را به‌عنوان ورودی سریع معرفی می‌کرد؛ در حالی که فایل قدیمی `crm-demo-standalone.html` فقط نسخه قبلی مدل را داشت و پیش‌نمایش‌های مراحل ۵ تا ۹ جدا بودند.

۳. منوی مشترک MVC برخی لینک‌ها را بدون بررسی مجوز ماژول نمایش می‌داد. برای نمونه، مدیر مالی لینک سرنخ‌ها را می‌دید، اما مقصد برای نقش او مجاز نبود. این لینک‌ها اکنون با همان Permission ماژول نمایش داده می‌شوند.

علت خطای یک URL آنلاین مشخص در این نوبت قابل اثبات نیست، چون نشانی یا تصویر خطای جدید ارائه نشده است. اصلاحات بر فایل‌های تحویل‌شده و کد فعلی پروژه اعمال شده‌اند؛ استقرار روی سایت آنلاین ادعا نمی‌شود.

## اصلاح اعمال‌شده

- ورودی واحد `index.html` و نسخه همسان `preview/crm-unified.html`، با منو، هدر، ورود و داده مشترک.
- ۱۱ مسیر اصلی: مرکز عملیات، مشتریان، سرنخ‌ها، فرصت‌ها، پیشنهادها، سفارش‌ها، نمایندگان، کارتابل، گزارش‌ها، هویت و ساختار سازمانی.
- لینک‌های Hash برای بازخوانی صفحه، عقب/جلو مرورگر، پیوند مستقیم گزارش و بازگشت از ریزداده.
- فعال‌شدن دکمه ورود پس از آماده‌شدن اسکریپت؛ جلوگیری از ارسال فرم ورود به URL و درج رمز در QueryString.
- نمایش پیام راهنما اگر محیط پیش‌نمایش اجرای JavaScript را محدود کند؛ عدم وابستگی به CDN، fetch، iframe یا فایل جانبی برای اجرای HTML نهایی.
- تحمل مسدودبودن Storage یا JSON خراب؛ داده محلی نمونه در فضای ذخیره مستقل از پیش‌نمایش قبلی.
- اتصال گزارش‌ها به همان مشتریان، فرصت‌ها، سرنخ‌ها، فاکتورهای نمونه و نمایندگان؛ تغییر هدف نماینده در ریزداده تحقق هدف منعکس می‌شود.
- ایجاد سفارش از همان پیشنهاد تأییدشده و جلوگیری از ساخت سفارش تکراری برای یک پیشنهاد.
- حفظ سرنخ تبدیل‌شده در مدل مشترک برای صحیح‌ماندن مخرج و صورت گزارش تبدیل؛ ایجاد مشتری و فرصت مرتبط.
- لینک فعال جزئیات پیشنهاد، سفارش و نماینده و ارتباط نماینده با پرونده مشتری.
- اصلاح منوی MVC متناسب با مجوز نقش و به‌روزرسانی متن صفحه ورود تا اولویت ۹.

## روش بازکردن

برای مشاهده نمونه، `index.html` یا فایل `crm-unified.html` را دانلود و با Chrome یا Edge باز کنید. نام کاربری `sales.manager` و رمز `Demo@1405` است. حساب‌های `reporting.ceo`، `finance.manager`، `channel.manager` و `sales.expert` نیز با همان رمز نمونه شناخته می‌شوند. داده‌ها ساختگی‌اند و امنیت سازمانی صرفاً در نسخه MVC سمت سرور اعمال می‌شود.

برای MVC: SDK 10 را نصب کنید، گواهی توسعه HTTPS را طبق README آماده کنید، `dotnet run --project src/Crm.Web` را اجرا و `https://localhost:7141` را باز کنید. بازکردن فایل Razor یا ZIP در مرورگر، اجرای ASP.NET نیست.

پیش‌نمایش HTML، نمونه تعامل است؛ همه جزئیات گردش‌های ERP، مجوزهای واقعی، EF، OIDC و ممیزی سمت سرور در آن شبیه‌سازی نمی‌شود. کد اصلی MVC و سرویس‌های اولویت ۹ در بسته حفظ شده‌اند.
