# کنترل کیفیت اولویت ۹

Workflow فعال: `.github/workflows/priority9-quality-gate.yml`؛ شامل تمام تست‌های مراحل قبل، .NET 10، SQL Server و Chromium است.

| سناریو | انتظار |
|---|---|
| مدیر فروش | Forecast، Pipeline و داده مجاز؛ بدون اطلاعات وصول |
| Expert با Profile مدیرعامل | فقط شعبه مجاز؛ بدون Export |
| ارسال BranchId دستکاری‌شده | رد دسترسی |
| DealerUser در `/reports` | رد دسترسی |
| Company C02 | عدم مشاهده Fact یا ابعاد C01 |
| دسترسی جداگانه منبع و Export | اشتراک دامنه‌ها، بدون Union ناامن |
| بازه معکوس، تاریخ خراب یا بیش از ۳۶۶ روز | 422 و حفظ فرم |
| ابتدا/انتهای روز | `[start,end)`؛ روز پایانی فرم شامل است |
| مخرج صفر | مقدار ناموجود |
| Forecast | جمع ارزش × احتمال؛ برابری KPI و ریزداده |
| Snapshot تکراری | عدم افزایش فروش نماینده |
| هدف ناهم‌دوره | حذف از نسبت و هشدار |
| داده مالی | فقط Invoice cohort؛ بدون استنتاج از Order.Paid |
| Export بدون CSRF/Permission | رد درخواست |
| CSV فرمولی با فاصله/Tab | خنثی‌سازی |
| بیش از ۵۰۰۰ ردیف | رد خروجی؛ بدون truncation |
| CSV و BI | ثبت Audit و حفظ Masking |
| فیلتر HTMX و Drilldown | پاسخ Partial و URL قابل Refresh |
| دانلود مرورگر | CSV با نام ثابت امن و MIME صحیح |

شواهد اجرای محلی و محدودیت‌های محیط در گزارش تحویل نهایی ثبت می‌شود. وجود فایل تست یا Workflow به معنی Pass شدن اجرای آن نیست. اولویت ۹ Schema جدید ندارد؛ تست Migration/Rollback اولویت ۸ همچنان در Gate تجمعی اجرا می‌شود.
