# فونت سازمانی (IRANSansX)

فایل‌های فونت ایران‌سنس تجاری‌اند و در مخزن قرار داده نشده‌اند. نسخهٔ دارای مجوز را (فرمت woff2) با همین نام‌ها در این پوشه بگذارید:

- `IRANSansX-Regular.woff2` (الزامی؛ وجود همین فایل فونت را فعال می‌کند)
- `IRANSansX-Medium.woff2`، `IRANSansX-DemiBold.woff2`، `IRANSansX-Bold.woff2`، `IRANSansX-ExtraBold.woff2` (اختیاری)

برای نمایش اعداد فارسی، فایل‌های نسخهٔ FaNum (مثلاً `IRANSansXFaNum-Regular.woff2`) را با همین نام‌ها ذخیره کنید. راهنمای کامل: `docs/brand-font-fa.md`.
